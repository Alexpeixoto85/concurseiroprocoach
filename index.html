📋 Como importar um concurso automaticamente ▼
1. Clique em ⬇️ Modelo JSON para baixar o arquivo de exemplo
2. Edite o arquivo com os dados do seu concurso (nome, orgao, data, materias)
3. Clique em 📥 Importar JSON e selecione o arquivo editado
4. O concurso sera cadastrado automaticamente com cronograma gerado!
🎬 Videoaulas
Organize e acompanhe suas aulas por matéria
🎬 Como importar videoaulas em lote ▼
1. Clique em Modelo JSON para baixar o arquivo de exemplo com a estrutura correta
2. Use o prompt abaixo no Claude para gerar uma lista de videoaulas do YouTube
3. Salve a resposta como .json e clique em Importar JSON
4. As videoaulas serao cadastradas automaticamente, sem duplicatas!
PROMPT PARA GERAR VIDEOAULAS COM O CLAUDE
Gere um arquivo JSON com videoaulas do YouTube para estudar [MATERIA] para o concurso de [CARGO/ORGAO]. Use o formato abaixo, com links reais do YouTube. Retorne APENAS o JSON, sem texto extra:
[{"url":"https://youtube.com/watch?v=ID","titulo":"Titulo da Aula","materia":"Nome da Materia","canal":"Nome do Canal","duracao":45,"obs":"Observacao opcional"}]
Inclua pelo menos 10 videoaulas variadas, de canais como Gran Cursos, Estrategia, Direcao Concursos e QConcursos. Organize por subtopico e ordene do basico ao avancado.

📋 Simulados
Pratique com simulados completos
📋 Como criar e importar simulados automaticamente ▼
1. Clique em Modelo JSON para baixar o arquivo de exemplo com a estrutura exata
2. Use o prompt abaixo no Claude para gerar um simulado completo com questoes e gabarito
3. Salve a resposta como .json e clique em Importar para enviar o arquivo
4. O simulado aparecera aqui pronto para ser realizado com cronometro e gabarito automatico!
PROMPT PARA GERAR SIMULADO COM O CLAUDE
Crie um simulado no formato JSON para o concurso de [CARGO/ORGAO], com foco em [MATERIA], no estilo da banca [BANCA ex: CESPE/VUNESP/FCC]. Retorne APENAS o JSON, sem texto extra, seguindo esta estrutura:
{"titulo":"Nome do Simulado","materia":"Materia","tempo":60,"questoes":[{"numero":1,"enunciado":"Texto da questao","opcoes":["A) ...","B) ...","C) ...","D) ...","E) ..."],"gabarito":"A","explicacao":"Explicacao da resposta correta"}]}
Gere 20 questoes ineditas e desafiadoras, cobrindo os principais topicos do edital. Cada questao deve ter 5 alternativas (A a E), gabarito correto e explicacao detalhada. O campo "tempo" e em minutos.
